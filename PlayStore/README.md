## 🚀 How to Run Locally

You can open and test this UI in several ways:

### Option 1: Direct Browser Open (No Node required)
Simply double-click `index.html` or open it with Google Chrome / Safari / Firefox:
```bash

```

### Option 2: Live Local Server
```bash
cd /Users/anilrathore/Documents/Project/Pravesh/PlayStore

# or
```
